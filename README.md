# Basketball_Shot_Game
A first-person mobile basketball game. Move with a joystick, pick up the ball, drag to aim, hold to charge, and release to shoot.

Features:-
1) Joystick movement and a Pickup button
2) Drag to turn and set the launch angle (25°–75°)
3) Hold Shoot to charge power (4–14 m/s), release to throw
4) Live trajectory preview of the ball path
5) Hoop scoring (ball must pass through from top to bottom)
6) Guide panel: angle, speed, score
7) Ball respawns 4 seconds after release

Controls:-
1)Move with the Left joystick
2)Pick up ball with the	Pickup button
3) Turn / set angle	Drag on screen
4)Charge and throw by pressing the	Hold / release Shoot
